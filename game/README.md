# LAVA CRAFT 3D（～ 天国まで逃げろ！ ～）

Ursina で作った 3D ゲーム。下から 上がってくる 溶岩から、ブロックを ほって・置いて 上へ にげる。高さ 120m の 天国に 着いたら クリア。

## 動かし方

```
pip install ursina
python lava_craft_3d.py
```

Windows なら `run_3d.bat` を ダブルクリックでも 起動できる。

## 操作

| キー | 動き |
|---|---|
| WASD / マウス / Space | 移動・見回す・ジャンプ |
| 左クリック | ブロックを ほる（資材が 手に入る） |
| 右クリック | ブロックを 置く（真下を 向いて ジャンプ中に 置くと のぼれる） |
| 1 / 2 / 3 | 置く 材料（木・石・鉄） |
| C | ジェット機（石 8・鉄 8） |
| Esc | メニュー |
