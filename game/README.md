# LAVA CRAFT 3D（～ 天国まで逃げろ！ ～）

Ursina で作った 3D ゲームです。たてに長い穴の中で、下から溶岩が上がってきます。ブロックをほって資材を集め、足場を作りながら上へにげます。高さ 120m にある天国の門に着いたらクリアです。

## 動かし方

```
pip install ursina
python lava_craft_3d.py
```

Windows なら `run_3d.bat` をダブルクリックしても起動できます。

- 最初の起動のときに、2つのものを同じフォルダに自動で作ります。
  - Windows のメイリオ（日本語フォント）のコピー
  - 効果音の wav ファイル（`sounds` フォルダ）
- どちらも GitHub にはのせません（`.gitignore` で外しています）。

## 操作

| キー | 動き |
|---|---|
| WASD / マウス / Space | 移動・見回す・ジャンプ |
| 左クリック | ブロックをほる（資材が手に入る） |
| 右クリック | ブロックを置く（真下を向いて、ジャンプ中に置くと上にのぼれる） |
| 1 / 2 / 3・ホイール | 置く材料を変える（木・石・鉄）。タイトルでは むずかしさを選ぶ |
| C | ジェット機（石 8・鉄 8 で、3秒間 一気に上へ） |
| Esc | メニュー（もどる / やめる） |
| R / T | ゲームオーバー後に、もう一度 / タイトルへ |

## ルール

- 溶岩は、はじめは止まっています。時間がたつと動き出し、だんだん速くなります。ときどき警告のあとに「波」が来て、一気に上がります。
- 上から石が落ちてきます。落ちる場所には影が出ます。当たると HP が 1 減ります。
- 材料には、それぞれ特ちょうがあります。
  - 木: 溶岩に近づくと燃えます。
  - 石: 落石でこわれます。
  - 鉄: 落石でもこわれません。
- エリアは「洞窟 → 森 → 空 → 天国」の順に変わります。上に行くほど鉄が多くなります。
- スコアは「時間 + いちばん高い所 × 10 + 置いた数 × 2」です。クリアすると +500 されます。むずかしさごとのベストスコアを保存します。

## プログラムのしくみ

ファイルは上から順に読めば分かるように、9つのまとまりに分けてあります。

| 番号 | 中身 | ポイント |
|---|---|---|
| ① 準備 | Ursina の起動、フォント、効果音 | 効果音は音のファイルを使っていません。`make_sound()` が サイン波・矩形波・ノイズを計算して wav を作ります |
| ② 設定 | 速さ・高さ・むずかしさなどの数字 | ここの数字を変えるだけで、ゲームバランスを調整できます |
| ③ ブロック | `Block` クラスと `make_layer()` | ブロックは `blocks` 辞書に「(x, y, z) → ブロック」で記録します。置く・ほる・当たり判定は、全部この辞書を使います |
| ④ けしき | 結晶・木・雲・金の柱・天国の門 | さわれない かざりです。かべのすきまから見えます |
| ⑤ プレイヤーと画面 | `FirstPersonController` と文字・バー | 右はしのバーで、天国までの進み具合と、溶岩の位置が分かります |
| ⑥ 落石など | `Rock` クラス、回復の実、ジェット機、かけら | 落石は `raycast()` で、真下の落ちる場所を先に調べて、影を出します |
| ⑦ ゲームの流れ | タイトル・スタート・ゲームオーバー・メニュー | 状態は `g.state`（`title` / `play` / `over` / `clear`）で管理します |
| ⑧ `input()` | キー・マウスを押したとき | ほる・置くは `mouse.hovered_entity`（画面の まん中で ねらっている ブロック）と `mouse.normal`（ねらった面の向き）で決めます |
| ⑨ `update()` | 毎フレーム（1秒に約60回） | 溶岩・落石・回復・ジェット機・画面の文字を、少しずつ進めます |

### 工夫したところ

- **軽くする**: プレイヤーの少し上までしか段を作りません。溶岩にしずんだ段は消します。
- **公平にする**: 落石は落ちる前に影を出します。溶岩の波は 3秒前に警告します。
- **3D でも分かりやすく**:
  - ねらっているブロックを白く光らせます。
  - 手に持っているブロックの色で、今の材料が分かります。
  - 溶岩が近いと画面が赤くなります。
