# LAVA CRAFT 3D（～ 天国まで逃げろ！ ～）

Ursina で作った 3D ゲームです。たてに長い穴の中で、下から溶岩が上がってきます。ブロックをほって資材を集め、足場を作りながら上へにげます。高さ 120m にある天国の門に着いたらクリアです。かべの奥にかくれた鍵を 3つ集めてクリアすると、真エンディングになります。

## 動かし方

```
pip install ursina
python lava_craft_3d.py
```

Windows なら `run_3d.bat` をダブルクリックしても起動できます。

- 最初の起動のときに、2つのものを同じフォルダに自動で作ります。
  - Windows のメイリオ（日本語フォント）のコピー
  - 効果音の wav ファイル（`sounds` フォルダ）
- テクスチャ（16×16 のドット絵）は、起動するたびにプログラムで描きます。画像ファイルはいりません。
- どちらも GitHub にはのせません（`.gitignore` で外しています）。

## 操作

| キー | 動き |
|---|---|
| WASD / マウス / Space | 移動・見回す・ジャンプ |
| 左クリック（長押し） | ブロックをほる。かたいブロックほど時間がかかる |
| 右クリック | ブロックを置く |
| Q（長押し） | 自分の真下にブロックを積んで 1段上がる。真下を見て右クリック長押しでも同じ |
| F | 剣をふる（敵をねらって左クリックでも OK） |
| B | ショップ（コインでお助けアイテムを買う） |
| 1 / 2 / 3・ホイール | 置く材料を変える（木・石・鉄）。タイトルでは むずかしさを選ぶ |
| C | ジェット機（石 8・鉄 8 で、3秒間 一気に上へ） |
| Esc | メニュー（もどる / 全画面 / やめる） |
| F11 | 全画面とウィンドウを切りかえる |
| R / T | ゲームオーバー後に、もう一度 / タイトルへ |

## ルール

- 溶岩は、はじめは止まっています。時間がたつと動き出し、だんだん速くなります。ときどき警告のあとに「波」が来て、一気に上がります。
- ブロックにはかたさがあります（雲 0.2秒・木 0.3秒・くず石 0.35秒・石 0.7秒・鉄 1.5秒）。
- 鉄は大事な鉱石なので、まわりを「くず石」（ほっても資材にならない）で囲ってあります。
- 敵が出ます（洞窟=コウモリ、森=スライム、空=カラス、天国=まよい天使）。飛ぶ敵は、近くで止まって赤く光ってから突進してきます。剣でたおすとコインがもらえます。
- ショップ（B）で、回復薬・資材パック・鉄・シールド・溶岩ストップ・鍵さがし・ジェット券を買えます。
- 洞窟・森・空に 1つずつ、鍵の入った宝箱がかべの中にうまっています。
- ゲームオーバーになると、やられた原因に合わせたヒントが出ます。
- 上から石が落ちてきます。落ちる場所には影が出ます。当たると HP が 1 減ります。
- 材料には、それぞれ特ちょうがあります。
  - 木: 溶岩に近づくと燃えます。
  - 石: 落石でこわれます。
  - 鉄: 落石でもこわれません。
- エリアは「洞窟 → 森 → 空 → 天国」の順に変わります。上に行くほど鉄が多くなります。
- スコアは「時間 + いちばん高い所 × 10 + 置いた数 × 2 + たおした敵 × 20 + 鍵 × 300」です。クリアすると +500、真エンディングならさらに +1000 されます。むずかしさごとのベストスコアを保存します。

## プログラムのしくみ

ファイルは上から順に読めば分かるように、9つのまとまりに分けてあります。

| 番号 | 中身 | ポイント |
|---|---|---|
| ① 準備 | Ursina の起動、フォント、効果音、テクスチャ | 効果音は `make_sound()` が波形を計算して作ります。テクスチャは `make_texture()` が 16×16 のドット絵を描きます |
| ② 設定 | 速さ・高さ・むずかしさなどの数字 | ここの数字を変えるだけで、ゲームバランスを調整できます |
| ③ ブロック | `Block` クラスと `make_layer()` | ブロックは `blocks` 辞書に「(x, y, z) → ブロック」で記録します。置く・ほる・当たり判定は、全部この辞書を使います |
| ④ けしき | エリアごとのかざりと光の粒 | 洞窟=光る結晶・つらら・光るキノコ・ホタル、森=大きな木・木もれ日・落ち葉、空=流れる雲・浮島・鳥、天国=金の柱・虹・光の玉。エリアごとに霧の色とこさも変わります |
| ⑤ プレイヤーと画面 | `FirstPersonController` と文字・バー | 右はしのバーで、天国までの進み具合と、溶岩の位置が分かります |
| ⑥ 落石・敵など | `Rock`・`Enemy` クラス、剣、回復の実、ジェット機、真下に積む | 落石は `raycast()` で落ちる場所を先に調べて影を出します。`pillar()` は体を 1段持ち上げてから、足の下にブロックを置きます |
| ⑦ ゲームの流れ | タイトル・スタート・ゲームオーバー・メニュー・ショップ | 状態は `g.state`（`title` / `play` / `over` / `clear`）で管理します |
| ⑧ `input()` | キー・マウスを押したとき | ほる・置くは `mouse.hovered_entity`（画面の まん中で ねらっている ブロック）と `mouse.normal`（ねらった面の向き）で決めます |
| ⑨ `update()` | 毎フレーム（1秒に約60回） | 溶岩・落石・回復・ジェット機・画面の文字を、少しずつ進めます |

### 工夫したところ

- **軽くする**: プレイヤーの少し上までしか段を作りません。溶岩にしずんだ段は消します。
- **公平にする**: 落石は落ちる前に影を出します。溶岩の波は 3秒前に警告します。
- **3D でも分かりやすく**:
  - ねらっているブロックを白く光らせます。
  - 手に持っているブロックの色で、今の材料が分かります。
  - 溶岩が近いと画面が赤くなります。
